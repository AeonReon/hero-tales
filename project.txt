Structure:
- /                          static PWA root (vercel serves as-is)
- /index.html                launcher — hero, "For today" feed, shelf tiles
- /tales.html                browse the two public-domain shelves
- /chronicles.html           browse the three written shelves
- /chronicle.html            single chronicle reader (cost + reckoning)
- /story.html                single story reader (campfire toggle)
- /keep.html                 the shelf-keeper — put away / bring back / export
- /random.html               surprise me, across every shelf
- /curate.html               walk the seed tales, approve or disapprove
- /assets/shell.css          the shared design language (Classical Mind shell)
- /assets/shell.js           shared plumbing: icons, shelves, the Keeper, PWA
- /assets/home.js            launcher + daily feed
- /assets/tales.js           tale browse       /assets/chronicles.js  chronicle browse
- /assets/chronicle.js       chronicle reader  /assets/keep.js        shelf-keeper
- /assets/style.css          page styles: story reader, campfire, keeper
- /assets/daily-data.js      QUOTES / THOUGHTS / MAXIMS / WORDS for the feed
- /assets/{feats,stands,ledger}-data.js   the chronicles
- /assets/story.js           story page logic, TTS, campfire mode
- /stories/library.json      story index (no bodies, for fast loading)
- /stories/bodies.json       { id: body } map
- /stories/baldwin-*.json    per-source intermediate files (for inspection)
- /data/*.txt                raw Gutenberg sources (not served, kept for re-parsing)
- /scripts/build_library.py  parser

To add a new source:
1. Drop the Gutenberg .txt into /data/
2. Add a BOOKS entry in scripts/build_library.py with body_start_marker + allow_titles
3. python3 scripts/build_library.py
4. Commit + push (Vercel auto-deploys)
